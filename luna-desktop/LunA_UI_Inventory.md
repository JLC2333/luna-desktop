## 2. 聊天页（ChatPage）— 核心页面

### 2.1 左侧栏

| 元素 | 类型 | 交互/状态 |
|------|------|-----------|
| **+ 新建对话** | 按钮 | 紫色实底，hover 加深到 `#3C3489`。点击创建新空对话 |
| **搜索对话** | 输入框 | 占位文字"搜索对话..."，聚焦时边框变紫色 |
| **筛选角色** | 下拉选择 | 默认"全部角色"，选择后只显示该角色的对话 |
| **对话列表项** | 卡片 | 点击切换当前对话。选中态深色底，未选中透明。支持固定/删除/标题编辑 |
| **「📌 图钉」固定按钮** | 图标按钮 | hover 浮现，点击固定/取消固定该对话，固定项置顶 |
| **「✕」删除按钮** | 图标按钮 | hover 浮现，点击弹删除确认条 |
| **标题编辑** | 内联输入框 | 双击标题文字进入编辑模式，Enter 确认，ESC 取消。历史页改为右键菜单修改 |

### 2.2 聊天主区域

| 元素 | 类型 | 交互/状态 |
|------|------|-----------|
| **角色选择器**（右上角） | 下拉选择 | 显示当前角色头像/名称。切换角色会清空当前对话消息。选择器在对话创建后出现 |
| **对话标题栏** | 文字/输入框 | 顶部显示对话标题，双击可内联编辑。Enter 保存，ESC 取消 |
| **角色信息横幅** | 展示区域 | 显示角色 emoji + 名称 + 世界观，在对话开始前展示。有点击查看详情区域 |
| **「☰ 角色与记忆」按钮** | 图标按钮 | 点击打开右侧上下文面板（380px 滑出） |

### 2.3 消息区域

| 元素 | 类型 | 交互/状态 |
|------|------|-----------|
| **消息气泡（用户）** | 气泡 | 靠右，`bg-luna-bg-secondary` 底，`rounded-br-md` 左下角。30px 灰色头像在气泡外左上角 |
| **消息气泡（AI）** | 气泡 | 靠左，`bg-luna-bg` 底带阴影，`rounded-bl-md` 右下角。角色 emoji 头像在气泡外左上角 |
| **系统消息** | 气泡 | 居左，淡红底 + 斜体，灰色角色头像 |

**消息 hover 操作按钮（用户消息）：**

| 按钮 | 图标 | 功能 |
|------|------|------|
| 引用回复 | 💬 | 点击引用该消息，底部输入框上方显示引用条 |
| 分支为新对话 | ↳ | 以该消息为起点创建新对话 |
| 编辑最后消息 | ✏ | 仅对**最后一条用户消息**显示，点击进入编辑模式 |
| 存入记忆 | 📌 | 将消息原文存入 `chat/{id}_memory.md`，保存后变绿"已保存"2s |
| 删除 | ✕ | 弹出删除确认条（"删除「XXX」？"+ 取消/确认），Enter 确认 |

**消息 hover 操作按钮（AI 消息）：**

| 按钮 | 图标 | 功能 |
|------|------|------|
| 引用回复 | 💬 | 同用户消息 |
| 分支为新对话 | ↳ | 以该消息为起点创建新对话 |
| 重新回答 | ↺ | 从上一个用户消息重新生成 AI 回复，回滚属性值 |
| 继续输出 | + | 让 AI 继续生成后续内容 |
| 删除 | ✕ | 同用户消息 |

### 2.4 输入区域（底部）

| 元素 | 类型 | 交互/状态 |
|------|------|-----------|
| **引用回复提示条** | 浮动条 | 显示"正在回复「xxx...」"+ ✕ 关闭按钮 |
| **文本输入框** | textarea | 支持多行，min-h-[48px] max-h-[120px]，Enter 发送，Shift+Enter 换行 |
| **发送按钮** | 按钮 | 常态：紫色箭头 ↑。生成中：红色方块 ■（停止）。消息为空或加载时 disabled |
| **滚动回底按钮** | 浮动按钮 | 消息区域未在底部时显示，点击跳回最新消息 |
| **统计面板入口** | 折叠区域 | 在消息区域底部，显示 8 个属性条（见后面），点击可展开详细面板 |

### 2.5 右侧上下文面板（380px 滑出）

| 元素 | 类型 | 交互 |
|------|------|------|
| **面板遮罩** | 半透明背景层 | 点击关闭面板 |
| **面板标题** | "角色与记忆" | 纯展示 |
| **「✕」关闭按钮** | 图标按钮 | 关闭面板 |
| **角色信息区** | 展示 | 角色 emoji + 名称 + 世界观 |
| **Soul（灵魂文件）** | 文本展示/编辑 | 显示灵魂文件内容，点击可进入编辑模式（textarea + 保存/取消按钮） |
| **Memory（记忆文件）** | 文本展示/编辑 | 显示该对话的 `memory.md`，点击可进入编辑模式（textarea + 保存/取消按钮） |
| **引用当前对话** | 按钮 | "在 Prompt 中引用该对话历史"，toggle on/off |
| **上下文 token 数** | 展示 | 显示当前已用 token 数 |

### 2.6 统计面板（StatsPanel 组件）

| 元素 | 类型 | 交互 |
|------|------|------|
| **属性条网格** | 展示 | 8 个属性，每个带 emoji + 彩色进度条 + 数值（0-100） |
| **属性条布局** | grid | 默认 4×2，≥1024px 切换 8×1 |
| **详细面板** | 弹窗 | 点击属性条区域展开，包含折线图（历史变化曲线）+ 所有属性滑块 |

8 个属性：活力/Vitality、智力/Intellect、情感/Emotion、道德/Morality、好感度/Affection、好奇心/Curiosity、松弛度/Relax、抑郁度/Depression

## 8. 全局 UI 模式

| 模式 | 说明 |
|------|------|
| **确认条**（替代原生 confirm） | 红色横幅，显示"删除「XXX」？"+ 取消/确认，支持 Enter 确认 |
| **Toast/提示** | 成功保存时绿色状态反馈（如"已保存"2s 自动消失） |
| **Loading 状态** | 按钮 disabled + 文本为灰色，提示"发送中" |
| **生成中状态** | 发送按钮变红色方块（停止），消息区显示打字指示器 |
| **清屏状态** | 每个列表/网格在空数据时显示居中灰字提示（"暂无角色"等） |

## 9. 特殊交互

| 交互 | 描述 |
|------|------|
| **对话分支** | 从任意消息创建新对话，非树结构，独立于原对话 |
| **重新回答** | 从上一个用户消息重新生成 AI 回复，rollback 属性值 |
| **继续输出** | 在当前 AI 消息末尾追加内容 |
| **软删除** | deleted_at 字段标记，可在回收站恢复 |
| **属性系统** | 8 维属性由 LLM 在回复中输出 `stat_deltas` 驱动变化 |
